# 株式会社トレーディング・ワン 建設機械買取LP

建設機械・重機の買取／販売に特化したランディングページ。`index.html` 1ファイルで完結（外部ファイル不要）。

## GitHub Pages で公開する手順（PC操作に不慣れな方向け）

1. GitHub にログイン → 右上「＋」→ **New repository**
2. Repository name に `trading-one-lp` と入力 → **Public** を選択 → **Create repository**
3. 作成後の画面で **uploading an existing file** をクリック
4. `index.html`（と、このREADME）をドラッグ＆ドロップ → **Commit changes**
5. リポジトリの **Settings** → 左メニュー **Pages** → Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**
6. 1〜2分後、ページ上部に公開URLが表示されます
   `https://<あなたのGitHubユーザー名>.github.io/trading-one-lp/`

このURLをそのままお客様に送れば、スマホでもPCでも閲覧できます。

## 差し替えが必要な項目

| 箇所 | 現在の内容 |
| --- | --- |
| 電話番号 | `099-000-0000`（仮） |
| 受付時間 | 8:30〜18:00（日曜・祝日休） |
| 写真 | Pexels のサンプル（商用利用可）。自社の実機・ヤード写真に差し替え推奨 |
| 販売中の機械 | サンプル3台。実在庫に差し替え |
| お客様の声 | サンプル3件。実際の声に差し替え |

`index.html` をテキストエディタで開き、上記の文字列を検索して置き換えてください。

## かんたん査定機能について

機種・年式・稼働時間・状態の4項目から概算レンジを表示します。係数は一般的な相場を仮置きしたものなので、実際の相場感に合わせた調整をおすすめします。
